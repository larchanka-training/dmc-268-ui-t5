# Запуск приложения: workflow

Приложение — Vite + React + TypeScript, точка входа `src/main.tsx`.

## Workflow: запустить и проверить

1. **Предусловия** — зависимости:
   ```bash
   npm install
   ```
2. **Запуск** (в фоне или отдельном терминале):
   ```bash
   npm run dev                     # http://localhost:5173; порт: -- --port 3000
   ```
3. **Проверка работоспособности** — последовательно:
   ```bash
   npm run build                   # ожидаем: tsc без ошибок + успешная сборка vite
   curl -s http://localhost:5173/  # ожидаем HTML с <div id="root"> и скриптом /src/main.tsx
   ```
   Считай шаг успешным, только если сборка прошла без ошибок и страница отдаёт ожидаемый HTML.
4. **При падении** — читай вывод vite/tsc из логов процесса; типовые причины: занятый порт, ошибка типов (`tsc`), неустановленная зависимость, битый импорт в `main.tsx`.

## Workflow: остановить

- Интерактивный процесс: `Ctrl+C`.
- Фоновый: `lsof -i :5173` → PID → `kill <PID>`; подтверди остановку повторным `curl` (ожидаем connection refused).

## Критерий успеха

- Dev-сервер запущен без ошибок в логах.
- `npm run build` завершается с кодом 0.
- `http://localhost:5173/` отвечает 200 с ожидаемым HTML.

Если критерий не достигнут — workflow не завершён: диагностируй по шагу 4 и повтори.
